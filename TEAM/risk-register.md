# NagarDrishti Risk Register

Likelihood and impact are assessed for the 12-week v1, not a future production service. Owners review their risks every Monday and raise an issue when an early signal appears.

## Top 5 risks to watch weekly

1. **R-12 scope creep:** check whether this week’s tasks still advance the critical path, not a Phase 2 idea.
2. **R-03 class imbalance:** inspect per-category and per-language metrics, not only accuracy.
3. **R-05 verifier gaming:** add one new adversarial proof-of-fix case whenever M5 changes.
4. **R-09 team capacity:** surface exam/availability conflicts before work is late; use the de-scope ladder early.
5. **R-13 demo reliability:** run the exact presentation path from a clean/stable environment beginning Week 8.

Weekly review asks: “Did an early signal appear? Is the mitigation still owned? Does the contingency change this week’s exit criterion?”
