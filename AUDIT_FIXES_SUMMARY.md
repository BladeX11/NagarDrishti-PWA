## 1. What Was Fixed & How It Works

### Auth, Routing, & Production Container
- **Scoped Authentication Gate ([AuthGate.tsx](./nagardrishti-frontend/client/src/components/auth/AuthGate.tsx), [App.tsx](./nagardrishti-frontend/client/src/App.tsx), [main.tsx](./nagardrishti-frontend/client/src/main.tsx)):** Moved `<AuthGate>` off the global `<App>` wrapper so public landing (`/`) and transparency routes (`/transparency/*`) load unauthenticated, while protecting `/officer/*`, `/research/*`, and authenticated citizen workflows (`/citizen/report`, `/citizen/my-reports`, `/citizen/issue/:id/verify`, `/citizen/notifications`, `/citizen/settings`). Exposed `researcher` and `admin` roles in the role selector and wired `authApi.logout()` across portal layouts and settings.
- **OTP & Session Hardening ([auth.ts](./nagardrishti-frontend/server/routes/auth.ts), [middleware/auth.ts](./nagardrishti-frontend/server/middleware/auth.ts)):** Removed synthetic non-UUID fallback IDs (`demo-*`, `user-*-001`) that caused PostgreSQL UUID FK errors; moved role/provisioning eligibility checks ahead of setting `otpChallenges.consumedAt`; added per-IP and per-destination OTP rate limiters; aligned `nd_session` `secure` cookie detection with TLS-terminating reverse proxies (`req.secure || x-forwarded-proto === 'https'`).
- **SPA Fallback & Dockerfile ([app.ts](./nagardrishti-frontend/server/app.ts), [Dockerfile](./nagardrishti-frontend/Dockerfile)):** Moved `/api` and `/api/*` 404 JSON handlers above the production `app.get('*')` SPA catch-all so unknown API routes return JSON 404 instead of `index.html`. Moved `ENV NODE_ENV=production` after `pnpm install --frozen-lockfile` in the runtime image so `drizzle-kit` and `tsx` remain available for boot migrations and seeding.

### Backend Services, Privacy, Workflow, & AI
- **Unified `idOrRef` Resolution & Enriched Responses ([issueService.ts](./nagardrishti-frontend/server/services/issueService.ts), [issues.ts](./nagardrishti-frontend/server/routes/issues.ts), [officer.ts](./nagardrishti-frontend/server/routes/officer.ts), [audit.ts](./nagardrishti-frontend/server/routes/audit.ts)):** Added `resolveIssueId` and UUID validation across issue mutations, verification, flags, and audit chain verification so `publicRef` values (`ND-xxx`) never hit PostgreSQL UUID cast errors (`500`). Mutation endpoints (`PATCH /:id`, `assign`, `status`) now return enriched `issueService.getIssue()` payloads with `events`, `department`, `ward`, `aiConfidence`, and coordinates. Aligned `POST /:id/proof` to `requireRole('officer', 'admin')`.
- **Privacy Redaction & Object Storage ([privacyService.ts](./nagardrishti-frontend/server/services/privacyService.ts), [scorecardService.ts](./nagardrishti-frontend/server/services/scorecardService.ts), [transparency.ts](./nagardrishti-frontend/server/routes/transparency.ts), [objectStorage.ts](./nagardrishti-frontend/server/services/objectStorage.ts)):** Wired `privacyService.redactForPublic()` across public issue, SLA breach, and forgotten issue responses so `privateLat`, `privateLng`, `reporterId`, and `privatePath` are stripped. Replaced unrenderable `s3://` public fallback paths with `null` and validated issue existence, ownership, and byte-level SHA-256 hashing on `/api/issues/:id/media` and multipart `req.file` uploads.
- **Transactional Hash Chain & Proof-Cycle Verification ([workflowService.ts](./nagardrishti-frontend/server/services/workflowService.ts), [verificationService.ts](./nagardrishti-frontend/server/services/verificationService.ts)):** Wrapped `appendStatusEvent` and `issues` status updates in `db.transaction` with row locking (`for('update')`) to prevent `prevHash` chain forks under concurrency; required `proofState` to be `submitted` or `accepted` before `Claimed Resolved`; scoped verification vote aggregation to `proofVersion`.
- **Research Route Protection & AI Confidence ([research.ts](./nagardrishti-frontend/server/routes/research.ts), [notifications.ts](./nagardrishti-frontend/server/routes/notifications.ts), [orchestrator.ts](./nagardrishti-frontend/server/ai/orchestrator.ts), [rules.ts](./nagardrishti-frontend/server/ai/rules.ts)):** Protected research endpoints with `requireRole('researcher', 'admin')`; replaced `/proof-audit` and `/metrics` stubs with real DB/evaluation queries; enabled `officer`, `admin`, and `researcher` on `/api/notifications`; propagated real confidence/signals into `calibratePrediction()`; aligned canonical department IDs (`roads`, `waste`, `water`, `drainage`, `electrical`, `animals`, `civic-works`) across `shared/types.ts`, `rules.ts`, and UI selectors.

### Frontend Portals, Offline Queue, & Service Worker
- **Citizen Portal ([pages/citizen/*](./nagardrishti-frontend/client/src/pages/citizen/CitizenHome.tsx), [CitizenLayout.tsx](./nagardrishti-frontend/client/src/layouts/CitizenLayout.tsx)):** Wired `VerificationVote`, `CitizenHome`, `ExploreMap`, `CitizenIssueDetail`, and `IssueCard` support buttons to live APIs (`issuesApi.get`, `issuesApi.list`, `mapApi.getMarkers`, `issuesApi.support`, `transparencyApi.getScorecard`). Fixed `MyReports` error masking, missing `Triaged`/`Assigned` filters, and offline queue visibility; fixed `Notifications` ID-based read tracking and filter keys; persisted `Settings` preferences and corrected `categoryDepartmentFor()` mappings.
- **Officer, Public, Research & Shared Components ([pages/officer/*](./nagardrishti-frontend/client/src/pages/officer/OfficerPages.tsx), [PublicPages.tsx](./nagardrishti-frontend/client/src/pages/transparency/PublicPages.tsx), [HeroLanding.tsx](./nagardrishti-frontend/client/src/pages/HeroLanding.tsx), [AnnotationWorkspace.tsx](./nagardrishti-frontend/client/src/pages/research/AnnotationWorkspace.tsx), [ResearchPages.tsx](./nagardrishti-frontend/client/src/pages/research/ResearchPages.tsx)):** Guarded `CategoryIcon`, `StatusBadge`, `ActivityTimeline`, and `EvaluationMetrics`; separated `IssueCard` `onSupport` from card links and added `basePath`/`linkBasePath` so mobile officer queue navigation stays inside `/officer/*`; synced `OfficerIssueDetail` department IDs, `VALID_TRANSITIONS`, live media, and proof submission; wired `PublicIssueDetail`, `PublicMap` ward normalization, `ResearchPages` live `researchApi`, `AuditLedger` `verifyGlobal()`, and authenticated Blob CSV export in `AnnotationWorkspace`. Isolated `HeroLanding` Leaflet stacking context and memoized Three.js geometry.
- **Offline Queue & PWA ([offlineQueue.ts](./nagardrishti-frontend/client/src/pwa/offlineQueue.ts), [sw.js](./nagardrishti-frontend/client/public/sw.js), [api.ts](./nagardrishti-frontend/client/src/lib/api.ts), [ErrorBoundary.tsx](./nagardrishti-frontend/client/src/components/ErrorBoundary.tsx)):** Added an in-flight mutex, `try/catch` DB cleanup, `4xx` failure isolation, and UUID fallback to `offlineQueue.ts`; deferred initial sync until `AUTH_READY_EVENT`; guarded `sw.js` navigation caching on `response.ok` and push JSON parsing; honored `VITE_API_BASE_URL` in `api.ts`; hid stack traces in production `ErrorBoundary`.

- **Follow-up Cleanup & Live Scorecard Breakdown ([PublicPages.tsx](./nagardrishti-frontend/client/src/pages/transparency/PublicPages.tsx), [api.ts](./nagardrishti-frontend/client/src/lib/api.ts), [ResearchPages.tsx](./nagardrishti-frontend/client/src/pages/research/ResearchPages.tsx)):** Extended `ScorecardData` typing with `byWard`, `byDepartment`, `snapshots`, and `weeklyMetrics` matching `scorecardService.computeScorecard()`, switched `Scorecards` ward/department cards and 12-week trend charts from seed data to live DB aggregations with `snapshots` fallback plus loading/empty states, and removed the unused `ExperimentMetrics`/`ChartPanel` exports in `ResearchPages.tsx`.
- **Production Smoke Test Remediations ([app.ts](./nagardrishti-frontend/server/app.ts), [vite.config.ts](./nagardrishti-frontend/vite.config.ts)):** Browser smoke testing against Railway production caught Helmet's default CSP (`img-src 'self' data:`) blocking OpenStreetMap tiles and `vite-plugin-manus-runtime` injecting a `script-src 'self'`-blocked inline runtime script into `dist/public/index.html`. Configured explicit Helmet CSP directives (allowing `https://*.tile.openstreetmap.org`, `blob:`, `data:`, `https:` images/API, and Google Fonts while preserving strict `script-src 'self'`) and gated dev-only Manus plugins to `command === 'serve'` (reducing built `index.html` from 368.26 kB to 1.31 kB).
